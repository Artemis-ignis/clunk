# Clunk 파일럿 모집 킷

> 이 문서의 사실 근거: 저장소 `README.md`, `docs/application/form-answers.ko.md`(Q3-2·Q4-1 파일럿 계획), `docs/application/verification-log.ko.md`, `public/llms.txt`, `db/schema.ts`, `app/api/`.

목표2(상용화) 1단계 준비물입니다. 외주·에셋 마켓·AI 생성 3D 에셋을 반복해서 게임에 넣는 인디·소규모 팀을 모아 무료 파일럿을 돌리고, 그 결과로 다음 단계를 정하기 위한 문서 묶음입니다.

## 파일럿 전제 (모든 문서 공통)

- **무료입니다.** 파일럿 기간 동안 사용료를 받지 않습니다.
- **결제는 데모입니다.** 크레딧·플랜 화면에 `DEMO MODE · 실제 결제 아님`이 표시되고 결제 사업자는 연결돼 있지 않습니다. 이 사실을 모집 글에도 온보딩에도 숨기지 않습니다.
- **공개 URL이 아직 없습니다.** 비공개 파일럿이며, 참여 팀은 로컬 실행 또는 초대 세션(동석·화면 공유)으로 사용합니다.
- **고객·매출·성능 수치가 아직 없습니다.** 모집 글·인터뷰·보고 어디에도 확보하지 않은 숫자를 쓰지 않습니다. 현재 확보한 사실은 로컬 실행 증거(`docs/application/verification-log.ko.md`)까지입니다.
- **1차 대상은 하나입니다.** 외주·마켓 에셋을 반복해서 통합하는 인디·소규모 게임 개발팀. 생성형 3D 도구 회사와 에셋 마켓은 후순위 세그먼트로 두고 이번 파일럿에서 쫓지 않습니다.

## 사용 순서

| 단계 | 하는 일 | 쓰는 문서 |
| --- | --- | --- |
| 1. 모집 | 커뮤니티·행사·SNS에 공고를 올리고 문의를 받습니다 | [recruit-post.ko.md](recruit-post.ko.md) |
| 2. 스크리닝 | 대상이 맞는 팀인지 짧게 확인합니다 | [interview-script.ko.md](interview-script.ko.md) 의 "탈락 조건" 절 |
| 3. 온보딩 | 첫 세션을 진행하고 실제 에셋으로 한 바퀴 돌립니다 | [onboarding.ko.md](onboarding.ko.md) |
| 4. 측정 | 2~4주 동안 사용 데이터를 모읍니다 | [metrics-plan.ko.md](metrics-plan.ko.md) |
| 5. 인터뷰 | 팀당 30분 인터뷰를 1회 진행합니다 | [interview-script.ko.md](interview-script.ko.md) |
| 6. 판정 | 검증 질문 3개에 답이 나왔는지 확인하고 계속·수정·피벗을 정합니다 | [metrics-plan.ko.md](metrics-plan.ko.md) 의 "판정 기준" 절 |

스크리닝은 2단계에서 한 번, 인터뷰 도입부에서 한 번 더 확인합니다. 첫 통화에서 놓친 조건이 실사용 뒤에 드러나는 경우가 있습니다.

## 파일럿을 시작하기 전에 채울 것

모집 글에 `[연락처]` placeholder가 들어 있습니다. 다음을 정하고 한 번에 치환하세요.

1. `[연락처]` — 디스코드 DM, 이메일, 오픈채팅 중 실제로 매일 확인하는 채널 하나. 여러 개 나열하면 답이 흩어집니다.
2. 세션 방식 — 로컬 실행 안내를 보낼지, 동석 세션으로 진행할지. 온보딩 문서의 A안/B안 중 하나를 고르세요.
3. 파일럿 기간 — 모집 글에 기간을 적을 거라면 실제로 지킬 수 있는 길이로. 적지 않아도 됩니다.
4. 인터뷰 녹음 여부 — 녹음할 거면 인터뷰 시작 시 동의를 받습니다.

모집 글에 함께 올릴 이미지 카드 2종도 같은 `[연락처]` 자리를 비워 두었습니다: [assets/recruit-card-square.png](assets/recruit-card-square.png)(1080×1080, 커뮤니티·SNS용) · [assets/recruit-card-wide.png](assets/recruit-card-wide.png)(1200×630, 링크 미리보기·공지용).

## 이 킷을 쓰면서 하지 말아야 할 것

- 참여 팀 수, 검사 건수, 절약 시간, 처리 속도를 확보 전에 쓰지 않습니다. "10팀 모집"은 목표이지 성과가 아닙니다.
- 아직 없는 기능을 있는 것처럼 쓰지 않습니다. 프로젝트별 커스텀 검사 프로파일, 팀 공유 워크스페이스, CI/CD 연동, 서버 측 재검증은 **로드맵**이며 현재 제품에 없습니다.
- "안전하게 최적화해 드립니다" 같은 보장 표현을 쓰지 않습니다. v1은 mesh 단순화·텍스처 재인코딩·Draco/Meshopt·양자화·애니메이션 변경을 하지 않고, 허용 목록 작업(빈 노드 제거, 중복 머티리얼 정리, 지정한 비런타임 메타데이터 정리, 별도 파일 재패킹)만 새 파일로 적용합니다.
- 검사 결과를 "게임에서 잘 돌아간다는 보증"으로 설명하지 않습니다. 판정은 선언된 정책 기준에 대한 판정입니다.
