# Clunk Series Native Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Clunk-owned Forge, Sprite, Material, Motion, Game Ready, and Market series from audited GitHub source material while keeping every existing real artifact and evidence contract intact.

**Architecture:** Add a focused `packages/clunk-series` module that owns source provenance, series descriptors, deterministic native authoring, material maps, and bundle manifests. Connect it to the existing Core inspection boundary and authenticated Studio/API surfaces. GitHub clones remain audit inputs outside the runtime, while the committed Clunk implementation is its own code.

**Tech Stack:** React 19, TypeScript, existing vinext routes, `packages/core`, `@gltf-transform/*`, `sharp` only at a Node-side boundary if required, current D1/R2 APIs, Node test runner, PowerShell.

**Spec:** `docs/superpowers/specs/2026-08-28-clunk-series-native-build-design.md`

## Global constraints

- Never reset, clean, delete, or overwrite unrelated user work.
- Do not use WSL, `bash.exe`, or any `.sh` initializer.
- Do not add external runtime calls as a substitute for Clunk-native functionality.
- Do not copy source or assets from a repository without a compatible license.
- Never claim an artifact is production-ready without parse, policy, optimize, fresh recheck, blocker, score, and downloaded-artifact reopen gates.
- Keep source bytes separate from generated bytes and record per-file SHA-256.
- Use `apply_patch` for source and documentation edits and explicit UTF-8 reads on Windows.
