# 벤치마크: Meshy AI (생성 부문 선두주자) vs Clunk

작성일: 2026-08-21. 출처: meshy.ai 공개 페이지 조사(요금 상세는 페이지 미표기로 미확인 —
추정치를 쓰지 않는다).

## Meshy가 하는 것 (조사 결과)

- 생성: 텍스트→3D, 이미지→3D, AI 텍스처링(PBR), 자동 리깅·애니메이션(600+ 모션), 3D 에이전트 챗.
- 출력: FBX/GLB/OBJ/USDZ(게임), STL/OBJ/3MF(3D 프린팅), PBR 텍스처 맵.
- 배포면: 웹 스튜디오 + API + CLI + **MCP 서버**(에이전트 연동) + Unity/Blender/UE 플러그인.
- 검증 기능: **3D 프린팅 지향**(워터타이트/매니폴드, 슬라이싱 준비, 자동 복구) + Low Poly 모드.
- 신뢰: ISO 27001·SOC2·GDPR, 대형 게임사 고객 표기.

## 격차 분석 — Clunk가 서는 자리

| 축 | Meshy | Clunk |
| --- | --- | --- |
| 생성 | 최상급 (전용 모델·리깅·텍스처) | 에이전트 절차 생성 레일(코드 기반, 로컬, Apache-2.0 스킬) |
| 게임 런타임 품질 게이트 | 없음 (프린팅 무결성 중심) | **핵심** — 엔진·목적별 프로파일 예산, finding, Game-Ready Score |
| 증명·감사 | 없음 | **핵심** — 해시 체인, 재검사 digest, Passport, watch manifest+ref |
| 프로젝트 규약 검사 | 없음 | 커스텀 프로파일(+P1: named-node·축·LOD 쌍 계약) |
| 로컬 우선 | 클라우드 생성 | 바이트는 브라우저/로컬, 서버엔 해시·결과만 |
| 출처 검증 | 없음 | P2: provenance 체인(원본→파생 해시 감사) |

**결론 — 경쟁이 아니라 상보**: Meshy(및 모든 생성기)의 출력은 GLB로 나오고, Clunk는
GLB가 어디서 왔든 검수·판정·증명한다. 생성기가 늘어날수록(에이전트 생성 포함)
"만든 것"과 "게임에 넣어도 되는 것" 사이의 간극이 커지고, 그 간극이 Clunk의 시장이다.
Meshy조차 MCP로 에이전트에 붙는 시대 — 에이전트 워크플로 한가운데에서
`생성(무엇이든) → clunk_inspect → 판정 → Passport`가 Clunk의 문장이다.

## 포지셔닝 문장 (사이트·신청서용)

> Meshy가 만들고, 에이전트가 만들고, 사람이 만들어도 — 게임에 들어가기 전 마지막 관문은
> Clunk다. 생성은 여럿, 판정과 증명은 하나.

## 액션

1. (완료) 자체 생성 레일 1차: docs/generate-pipeline.ko.md — 에이전트 생성→GLB→게이트 실증.
2. (P0 연계) 텍스처 세트 검사가 생기면 Meshy류 PBR 출력물 검수 커버리지가 완성된다.
3. (후속) Meshy MCP ↔ Clunk MCP를 한 에이전트 세션에서 잇는 데모(생성 즉시 판정) —
   시연 영상 소재로 강력. 실행 전까지는 "계획"으로만 표기.
