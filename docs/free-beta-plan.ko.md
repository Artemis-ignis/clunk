# 무료 베타 → 유료 전환 계획 (2026-09-02)

마스터 결정: 통신판매업 신고는 보류(자금 없음), 결제 없이 **무료 베타**로 사용자부터 모은다. 돈 드는 일은 하지 않는다.
이 문서는 그 결정을 실제 숫자와 근거로 고정한다. 모든 가격은 2026-09-02에 화면에서 직접 확인한 값이다.

## 2. Clunk 원가 (실측)

- 이미지 1장 = 129.6뉴런 (flux-1-schnell, 2026-09-01 실측). Cloudflare 유료 단가 $0.011/1k뉴런 → **약 ₩2/장**. flux-2-dev는 6,000뉴런 → 약 ₩91/장.
- 3D 제작(팩토리 실행·검사)·스프라이트 베이킹·팔레트 측정 = 워커 CPU만, 사실상 0원.
- 저장 R2 37.8MB(무료 10GB의 0.37%).
- 진짜 비용은 무료 구간을 넘는 순간의 **Workers 유료 $5/월**과 **Workers AI 초과분**이다. 그래서 베타 한도(`app/api/_lib/ai-budget.ts`: 하루 8,500뉴런 ≈ 65장, 작업공간당 8장)가 먼저다.

## 3. Clunk 가격 (계획 — 베타 중엔 표시만, 결제 없음)

크레딧은 그대로 **1크레딧 = ₩100**을 유지한다. 근거: Meshy가 ₩29/크레딧에 "크레딧 10개 = 에셋 1개"를 팔므로 에셋 1개 ≈ ₩290. Clunk는 이미지 1장·검사 1회·3D 제작 1회를 **각 1크레딧(₩100)**으로 받는다 — 같은 결과물 기준으로 레퍼런스보다 싸고, 원가율은 이미지 2%다.

| 플랜 | 가격 | 들어 있는 것 | 왜 이 숫자 |
|---|---|---|---|
| **Free** | ₩0 | 가입 시 25크레딧, 이후 **월 30크레딧**, 이미지 하루 8장, 마켓 미리보기·검사·MCP | Polyfork처럼 API/MCP는 무료에 둔다(에이전트 유입이 우리 차별점). 월 30은 Meshy Free(≈10개)의 3배 |
| **Maker** | **₩9,900/월** (연 ₩99,000) | 월 300크레딧, 마켓 다운로드 무제한, 이미지 하루 30장, 우선 처리 | Polyfork Pro $10와 같은 자리. Meshy Pro(₩28,869)의 1/3 가격에 크레딧 수는 1/3 — 크레딧당 단가는 같고 진입은 낮춤 |
| **Studio** | **₩29,000/월** (연 ₩290,000) | 월 1,200크레딧, 이미지 하루 100장, 팀 좌석 3, 상업 라이선스 명시 | Meshy Pro와 같은 가격대에서 크레딧 20% 더 |
| **크레딧 팩** | 500 = ₩45,000 · 2,000 = ₩160,000 · 6,000 = ₩420,000 | 만료 없음 | ₩90→₩80→₩70/크레딧, 구독보다 비싸게(구독 유도) |

현재 D1의 QA 팩(1,000크레딧 ₩9,900 = ₩9.9/크레딧)은 사이트가 여섯 번 말하는 ₩100/크레딧과 모순이므로 **폐기**한다.

## 4. 결제를 어떻게 붙일 것인가 (돈 안 드는 순서)

**0단계 — 지금(무료 베타), 비용 0원.** 신고·PG·MoR 모두 안 한다. 팔지 않으면 '통신판매'가 아니다(전자상거래법 제2조 정의; 공식 해석은 없음). 대신 지금 반드시 갖출 것: 개인정보처리방침 실효(보호책임자 = 대표 본인, 개인정보 보호법 제31조 소상공인 규정), 이용약관 실효, 푸터 사업자 정보, AI 생성물 표시.

**1단계 — 첫 유료, 가입비 0원.** **Merchant of Record**로 시작한다. 판매자가 그쪽이 되어 세금·환불·분쟁을 떠안고, 매출 0이면 비용도 0이다.
- **Polar**: 5% + 50¢, 월정액 0, 한국 판매자 명시 지원, 구독+단건+크레딧 한 곳, 정산 최소 $10.
- **Paddle**: 5% + 50¢, KRW 표시 가능, 더 성숙, 정산은 USD(최소 $100).
- 국내 PG는 선불 비용이 있다: 토스 가입비 22만 + 연 11만(VAT 별도), KCP/NICE 등록비 20~33만(면제 프로모션 있음). 매출이 생긴 뒤에 붙인다.

**2단계 — 통신판매업 신고.** 면제 기준(공정위 고시 2022-4호): **직전년도 거래 50회 미만 또는 간이과세자**면 신고 자체가 면제. 신고하게 되면 등록면허세 연 40,500원(인구 50만 이상 시)뿐이고, 카드 결제 디지털 상품은 에스크로 의무에서 제외(제24조③).

→ **마스터 확인 필요:** 아르테미스 사업자가 **간이과세자인지**. 맞으면 첫해 신고 부담이 사실상 없다.

## 5. 베타에서 마켓은 어떻게 동작하나

- 모든 상품은 **로그인한 사용자에게 무료**. 가격은 취소선 + "베타 무료"로 표시(유료 전환 후 값을 미리 보여 주는 효과). 다운로드가 곧 가입 유도다.
- 비로그인: 미리보기·스펙·팔레트·3D 뷰어까지 전부 공개, 받기 버튼만 "로그인하고 무료로 받기".
- 크레딧은 검사·생성에 계속 쓴다(가입 25 + 월 30). 한도에 닿으면 한국 시간 재개 시각을 알려 준다.
- "통신판매업 신고 절차가 끝나면…" 계열 문구 14곳은 전부 **"지금은 무료 베타"** 문구로 바뀐다. 약관·방침·환불정책은 시행일을 실제 날짜로 고정하고, 유상 조항은 "유료 전환 시 적용" 부록으로 분리한다.

## 6. 절대 넘지 않을 선

`npm run cf:usage`로 확인. Workers 일 10만 요청, Workers AI 일 1만 뉴런(우리 상한 8,500), R2 10GB·Class A 월 100만·Class B 월 1,000만. R2를 켜며 붙은 `r2_paid` 구독은 이 안에서 $0이다.
