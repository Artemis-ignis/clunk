# Clunk 용어 사전 (방문자 화면)

한 개념을 화면마다 다른 말로 부르면, 읽는 사람은 그것이 다른 물건인 줄 압니다.
이 표는 **공개 페이지에서 쓸 한 단어**를 정합니다. 새 문장을 쓰기 전에 여기부터 봅니다.

기준은 두 가지입니다.

1. 내비게이션과 푸터에 적힌 이름표가 그 화면의 이름입니다. 본문은 그 이름을 그대로 씁니다.
2. 여기 없는 말이 필요하면, 먼저 이 표에 한 줄을 더한 다음 화면에 씁니다.

---

## 1. 화면 이름

| 화면 | 쓸 이름 | 쓰지 않을 말 |
| --- | --- | --- |
| `/studio` | **에셋 제작** | 에셋 만들기(이름표로), 스튜디오, 만들기 화면, 작업면 |
| `/marketplace` | **에셋 마켓** | 에셋 장터, 상점, 카탈로그, 마켓플레이스 |
| `/app` | **에셋 검사** | 검사기, 인스펙터, 검수기 |
| `/review` | **검수 뷰어** | 리뷰 화면, 뷰어, 직접 검수기 |
| `/agents` | **제작 에이전트**(이름표) · **에이전트 연결**(그 화면의 제목) | AI 도구 연결(화면 이름으로), 커넥트, MCP 페이지 |
| `/webmcp` | **브라우저 도구(WebMCP)** | WebMCP 매니페스트, 인페이지 도구 |
| `/pricing` | **요금** | 요금 · 실행 횟수, 가격, 플랜 |
| `/dashboard` | **대시보드** | 내 작업공간, 마이 페이지, 워크스페이스 |
| GitBook | **문서** | 매뉴얼, 가이드, 독스 |

> `/connect`, `/mcp`, `/docs/*`, `/signin-with-chatgpt` 는 화면이 아니라 리다이렉트입니다.
> 목록·문서에 적을 때는 "…로 보냅니다"라고 밝히고, 독립된 화면인 것처럼 적지 않습니다.

## 2. 물건

| 개념 | 쓸 말 | 쓰지 않을 말 |
| --- | --- | --- |
| 게임에 넣는 파일 전반 | **에셋** | 리소스, 어셋, 자산, 콘텐츠 |
| GLB/glTF 한 개 | **3D 모델** | 메시, 모델링, 3D 파일 |
| 낱장 PNG | **2D 이미지** | 텍스처(표면용일 때만 텍스처), 그림 파일 |
| 여러 방향·프레임을 한 장에 구운 PNG | **스프라이트 시트** | 아틀라스, 시트, 스프라이트 |
| 관절을 돌려 만든 움직임 | **애니메이션 클립** | 모션, 클립, 애님 |
| 뼈대가 붙은 2D 움직임 | **본 애니메이션** | 스파인, Spine |
| 표면에 쓰는 이미지 묶음 | **텍스처** | 머티리얼, 재질 이미지 |

## 3. 하는 일

| 개념 | 쓸 말 | 쓰지 않을 말 |
| --- | --- | --- |
| 파일을 새로 만드는 일 | **만들기** (동사) / **에셋 제작** (화면 이름) | 생성, 제너레이션, 뽑기 |
| 파일을 열어 규격·규칙을 기계가 측정하는 일 | **검사** | 검증, 점검, 감사, 밸리데이션 |
| 사람이 뷰어에서 눈으로 돌려 보는 일 | **검수** (그리고 그 화면은 `검수 뷰어`) | 리뷰, 확인, 검사 |
| 원본은 두고 정리한 새 파일을 만드는 일 | **수정** | 최적화, 옵티마이즈, 정리 |
| 측정한 값 | **측정값 / 측정한** | 잰 값 / 재다 / 재서 / 잰 / 재면 / 잽니다 |
| 파일의 SHA-256 | **파일 지문** | 해시(문장에서), 다이제스트 |
| 검사 결과를 봉인한 기록 | **검사 증명서** | 패스포트, 여권, 증서 |

## 4. 판정 네 단계

에이전트가 이어서 수행하는 네 단계입니다. 네 칸 상태판은 **이 이름 그대로** 씁니다.

| 칸 | 쓸 이름 | 비어 있을 때 쓸 말 |
| --- | --- | --- |
| 1 | **파일 검사** | — (여기는 언제나 결과가 있습니다) |
| 2 | **엔진 렌더** | 증거 없음 · "엔진에서 그린 화면이 아직 없습니다" |
| 3 | **게임 시점** | 확인 전 · "게임 안에서 본 장면이 아직 없습니다" |
| 4 | **판정** | 보류 · "앞의 두 단계가 채워지면 판정합니다" |

쓰지 않을 말: `엔진 화면`, `게임 화면`(칸 이름으로), `사람 검토`, `사람 검토 대기`,
`사람이 직접 보고 판단해야 합니다`, `사람의 검토로 보냅니다`.

빈 칸은 **방문자에게 시킬 일**이 아니라 **지금 상태**로 적습니다.
"엔진에서 찍은 화면이 필요합니다"(숙제) → "엔진에서 그린 화면이 아직 없습니다"(상태).

## 5. 돈

| 개념 | 쓸 말 | 쓰지 않을 말 |
| --- | --- | --- |
| 파는 것 | **무료**와 **구독**, 둘뿐 | 유료 플랜, 프로, 프리미엄, 구독자 전용(요금제 이름으로) |
| 기간제 이용권 | **구독** | 멤버십, 정기결제, 패스 |
| 만들기·검사를 한 번 실행할 수 있는 단위 | **실행 횟수** (문장에서는 `만들기·검사 N회`) | 크레딧, 코인, 포인트, 토큰, 충전 |
| 등급 | **B · A · S 등급** | 티어, 레벨, 랭크 |
| 지금 상태 | **지금은 결제를 받지 않습니다** | 베타, 무료 베타, 프리뷰, 얼리액세스 |

- 낱개 가격·크레딧 단가·충전은 **어디에도 적지 않습니다.** 기계가 읽는 응답(`/api`,
  `/llms.txt`, `/prompt.txt`)도 같습니다.
- "가장 많이 고릅니다" 처럼 구독자 수를 전제한 말은 쓰지 않습니다. 구독이 아직 열리지 않았습니다.

## 6. 연결

| 개념 | 쓸 말 | 쓰지 않을 말 |
| --- | --- | --- |
| 밖의 AI 도구를 Clunk에 잇는 일 | **AI 도구 연결(MCP)** | MCP 연동, 통합, 인테그레이션 |
| `/api/mcp` 로 오는 도구 | **웹으로 바로 쓰는 도구** (필요하면 괄호로 `HTTP`) | HTTP 원격 도구, 리모트 툴 |
| 내 컴퓨터에 설치해 쓰는 도구 | **내 컴퓨터에서 쓰는 도구** (필요하면 괄호로 `로컬 stdio`) | 로컬 stdio 도구, 스튜디오 서버 |
| 발급받는 값 | **내 계정 전용 키** / **연결 키** | API 키(화면에서), 토큰, 시크릿 |
| 화면이 브라우저에서 직접 내주는 도구 | **브라우저 도구(WebMCP)** | 인페이지 도구, WebMCP 툴 |

## 7. 문장 규칙

- 영어 식별자에 한국어 조사를 바로 붙이지 않습니다.
  `bytesBase64를` (X) → `bytesBase64 값을` (O), `endpoint를` (X) → `연결 주소를` (O).
- 화면이 자기 제작 과정을 말하지 않습니다. 날짜 붙은 수정 이력, "우리가 틀렸었다",
  "이 숫자는 손으로 적지 않았다" 류는 코드 주석으로 옮깁니다.
  (예외 한 가지: "파일에서 측정한 폴리곤 수" 처럼 사는 사람이 출처를 알아야 하는 한 마디.)
- 숫자와 기능은 코드·파일에서 확인되는 것만 적습니다. 확인이 안 되면 지웁니다.
- 빈 상태와 오류 문장은 **다음에 무엇이 되는지**를 말합니다.
  "준비 중입니다."(끝) → "준비가 끝나면 위 버튼이 켜집니다. 그동안 에셋 마켓은 그대로 둘러볼 수 있습니다."
