# 모두의 창업 2차 일반·기술트랙 자격·접수 체크리스트

이 문서는 신청자를 대신해 자격을 판정하지 않습니다. 각 항목은 마스터가 본인 사실관계와 공식 플랫폼에서 직접 확인한 뒤 표시해야 합니다. 공고 원문과 live form의 최신 안내가 이 문서보다 우선합니다.

## 1. 신청 기본 조건

- [ ] 트랙을 `일반·기술트랙`으로 선택했다. 로컬트랙과 중복 신청하지 않는다. (공고 1, 15쪽)
- [ ] 신청 아이디어는 1개이며, 신청자 본인이 직접 착안한 아이디어다. (공고 15쪽)
- [ ] 신청자는 대표자 본인 명의로 모두의 창업 플랫폼에 회원가입·간편로그인·본인인증을 완료한다. (공고 1, 9쪽)
- [ ] 팀으로 신청할 경우 플랫폼의 대표자·본인인증 정보가 실제 대표자와 일치한다. (공고 9쪽)
- [ ] 제3자 대필·허위 작성·표절·도용 없이 신청 내용을 직접 검토하고 제출한다. (공고 14~15쪽)

## 2. 예비창업자 자격

마스터는 예비창업자로 신청할 계획이므로 아래를 우선 확인합니다.

- [ ] 공고일인 2026-08-20 기준 신청자 명의의 개인사업자·법인사업자 등록이 없다. (공고 3쪽)
- [ ] 사업자등록사실여부증명원을 발급할 수 있고, 1R 진출 시 운영기관이 정한 기한 안에 제출할 수 있다. (공고 6쪽)
- [ ] 부동산임대업 개인사업자 예외에 해당한다고 판단하는 경우, 직원이 없고 부동산임대업만 영위하며 향후 이종 업종 법인 창업이 가능한지 별도로 확인한다. 해당하지 않으면 이 예외를 주장하지 않는다. (공고 3, 6쪽)
- [ ] 지역주택조합 대표 예외를 주장하는 경우, 공고가 정한 공동대표·사업자등록사실 조건을 증빙할 수 있는지 확인한다. 해당하지 않으면 이 예외를 주장하지 않는다. (공고 3, 6쪽)

예비창업자 자격은 이 체크리스트의 표시만으로 확정되지 않으며, 공고가 요구하는 증빙서류로 확인됩니다.

## 3. 신청 제외 대상 자체 확인

다음 항목 중 하나라도 사실이면 신청 전 공식 문의가 필요합니다. 예외 조건이 있는 항목은 공고 원문을 함께 확인합니다.

- [ ] 금융기관 등으로부터 채무불이행 규제를 받고 있지 않다.
- [ ] 국세·지방세를 체납 중이지 않다.
- [ ] 창업진흥원 환수금 등 반환이 종결되지 않은 상태가 아니다.
- [ ] 일반·기술트랙에서 금지하는 업종을 영위하거나 영위할 계획이 아니다. 공고상 예시는 일반유흥주점, 무도유흥주점, 카지노 운영, 기타 사행시설 관리·운영 등이다. (공고 5, 28쪽)
- [ ] 2026년 중소벤처기업부 창업사업화 지원사업을 선정받아 수행 중이거나 동시에 수행할 예정이 아니다. 예비창업패키지, 초기·도약·초격차·TIPS·창업중심대학·청년창업사관학교·재도전성공패키지 등 공고 참고 2와 추가 공고를 확인한다. (공고 5, 8, 31~32쪽)
- [ ] 중소벤처기업부 창업지원사업 참여 제한 제재 중이 아니다.
- [ ] 창업진흥원이 지정한 사업비 계좌 개설·거래가 불가능한 상태가 아니다.
- [ ] 2026년 모두의 창업 지역허브기관·멘토기관의 제한 대상 인력 또는 멘토가 아니다.
- [ ] 고용노동부 체불사업주 명단에 포함되어 있지 않다.
- [ ] 보조금 관리 법령상 보조사업 수행 배제 대상이 아니다.
- [ ] 1차 모두의 창업에서 2R 통과 후 사업 수행 중이거나, 지원을 받고 정당한 사유 없이 중도 포기한 상태가 아니다.
- [ ] 그 밖에 중소벤처기업부 장관이 참여를 제한할 정당한 사유가 없다. (공고 4~5, 14~18쪽)

## 4. 제출물·마감

- [ ] 신청 기간을 확인했다: 2026-08-20 ~ 2026-09-17 16:00 (KST). (공고 9쪽)
- [ ] 마감 2~3일 전까지 live form 입력·첨부·제출을 끝내는 개인 일정을 잡았다. (공고 9쪽)
- [ ] `도전하기`에서 신청서를 직접 입력하고, live form의 필수 문항·글자 수를 확인했다. 공고상 신청서 외 별도 서류는 없지만, 후속 자격 검증 서류는 별도 안내될 수 있다. (공고 9쪽)
- [ ] 선택 이미지가 10장 이내이고 JPG·PNG·GIF 형식이다. (공고 9쪽)
- [ ] Clunk 증거 이미지는 실제 실행 화면이며, 이미지에 사후 합성한 수치·가짜 결과·분석을 위조하는 ImageGen 화면을 넣지 않았다.

- [ ] 숏폼 URL의 공개 권한·재생·길이·화면 내용이 제출 전 확인되었다.
- [ ] 신청·최종 제출 후 알림톡을 수령하고 홈페이지에서 최종 접수 결과·접수번호를 확인한다. (공고 9쪽)
- [ ] 모집종료 후에는 제출한 내용의 수정·삭제가 불가능하다는 점을 알고 있다. (공고 9쪽)
