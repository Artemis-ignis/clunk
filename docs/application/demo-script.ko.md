## 자막 언어 원칙

- 자막과 내레이션은 한국어로만 작성합니다. 영상에는 음성을 넣지 않았고, 음성을 추가할 경우에도 한국어 외 언어는 사용하지 않습니다.

## 상태 라벨 표기

- 이 영상은 2026-08-21 프리미엄 다크 재구축 이후의 UI이며, 2026-08-20에 도입한 3단계 상태 라벨을 그대로 유지합니다. 최적화 재검사 패널과 대시보드 이력에는 이전의 2단계 표기 대신 `조건부 준비`가 나타납니다.
- `조건부 준비`는 “차단 finding은 없지만 무손실 정리로 고칠 수 없는 경고가 남아 수동 확인이 필요하다”는 뜻입니다. 자막에서 이를 “통과”나 “문제 없음”으로 바꿔 말하지 않습니다.
- 재검사 점수가 100이어도 라벨은 `조건부 준비`입니다. 점수와 라벨을 같은 뜻으로 묶어 말하지 않습니다.

## 사용 제한

- 영상에서 확인하지 않은 사용자 수, 매출, 처리 성능, 유료 전환율은 말하지 않습니다.
- `99 → 100`, `2 → 1`, `1 → 0` 같은 숫자는 해당 샘플의 실제 화면에 표시된 값만 사용합니다.
- 실제 결제가 아니라는 점은 제품 화면의 `DEMO MODE · 실제 결제 아님` 표기로 구분합니다.
- 현재 파일은 로컬 실행 증거입니다. 공식 접수용 URL, 공개 권한, 재생 확인은 마스터의 최종 확인이 필요합니다.
