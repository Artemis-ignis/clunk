# 에셋 통합 규칙 원장 (게임 제작 에이전트 지식 베이스)

실게임 협업(1석 4조 루프)의 인게임 검증 회신에서 **규칙화 가능한 지식만** 축적합니다.
각 규칙은 실제 배치·실측에서 나온 것이며, 출처(게임/run-id/일자)를 함께 보존합니다.
이 원장은 Clunk 게임 제작 에이전트(3축)의 배치·생성·통합 판단 근거로 소비됩니다.

## R-001 · 수치 동률권에서는 형태 언어가 결정한다

- **규칙**: 판독성 밴드 수치가 동률권(같은 등급대)인 후보들 사이에서는 레퍼런스의
  형태 언어 계약(예: "fine broken clods, **irregular**")이 수치보다 상위다.
  특히 **동형 반복 요소(균일 원형 클로드 등)는 게임 거리에서 다른 재질(자갈/조약돌)로
  오독될 수 있다** — 생성 프롬프트에 불규칙성·비동형성을 명시하라.
- **증거**: soil-tilled 교체 A/B에서 v2(15m 46.4% B)가 아닌 v3(36.9% B)가 채택됨.
  v2의 균일 원형 클로드가 1.2 m/tile 거리에서 조약돌로 읽혔다.
- **출처**: Harvest Frontier · run-id HF-M319-soil-v3-ab · 커밋 b9e0c74 · 2026-08-31.
- **적용면**: 2D 텍스처 생성 프롬프트 규율, 마켓 등록 전 human review 질문지.

## R-002 · 밝기가 다른 교체본은 소비자 게인 재유도가 필수 통합 단계다

- **규칙**: 기존 자산을 교체하는 납품에서 평균 휘도가 크게 달라지면, 소비 엔진
  쪽에서 게인/노출 재유도가 반드시 필요하다(맵×버텍스컬러 구조 엔진은 특히).
  따라서 **텍스처 납품 기록에는 선형 Rec.709 평균 휘도(meanLinearLuminance709)를
  필수로 싣는다** — 소비자가 재측정 없이 게인을 재유도할 수 있도록.
- **증거**: soil-tilled v3 교체 시 평균 선형 휘도 0.0276 → 0.0551, HF 지면 게인
  3.710 → 1.859 재유도 필요했음.
- **출처**: Harvest Frontier · TEXTURE_MEAN_LINEAR_LUMA 테이블 운용 · 2026-08-31.
- **적용면**: `scripts/luna-imagegen.ts` 기록 스키마(구현됨), 텍스처 팩 매니페스트.

## R-003 · 캐노피 질량·높이는 카메라 여유 게이트의 입력이다

- **규칙**: 시장·도로변 구조물의 캐노피(차양·지붕 돌출)는 소비 게임의
  camera-clearance 게이트 검사 대상이다. 신규 구조물은 기존 배치물과 캐노피
  높이·돌출량을 비슷한 범위로 절제하고, 스케일 실측(m)을 납품 기록에 명시한다.
- **증거**: HF 상설 게이트가 시장 2지점에서 렌즈→플레이어 시야를 검사(M313 수리
  이력). 노점 수주 시 캐노피 3.2m 이하·돌출 0.5m 이내 요구.
- **출처**: Harvest Frontier 수주서 · 2026-08-31. (배치 캡처 회신 도착 시 갱신)
- **적용면**: 3D 구조물 팩토리 스펙, 납품 매니페스트의 스케일 필드.
