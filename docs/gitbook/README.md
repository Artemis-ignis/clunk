# Clunk 문서

Clunk는 게임 에셋을 **만들고, 게임에 넣어도 되는지 검사하고, 받아 쓰는** 곳입니다. 2D 이미지는 문장으로, 3D 모델과 스프라이트 시트는 코드로 만들고, 만든 파일은 그 자리에서 검사합니다. Claude Code·Cursor 같은 AI 도구에서도 같은 기능을 부를 수 있습니다.

제품 사이트: [clunk.games](https://clunk.games) · 지금은 무료 베타입니다.

## 검사 결과를 읽는 법

Clunk는 한 파일을 네 가지 방법으로 봅니다. 하나가 통과했다고 다른 것도 통과한 것으로 치지 않습니다.

| 검사 | 무엇을 보나 | 지금 자동으로 되나 |
| --- | --- | --- |
| 파일 검사 | 파일을 직접 열어 무게(면 수)·그리기 횟수·재질 수·텍스처 메모리를 세고, 고른 게임 기준에 맞는지 봅니다 | 예 |
| 화면 검사 | 실제 렌더러에 띄워 그림이 제대로 나오는지 봅니다 | 3D 모델은 예, 텍스처는 아직 아니오 |
| 게임 화면 검사 | 실제 게임 안에서 봤을 때 괜찮은지 봅니다 | 아니오 — 사람이 봐야 합니다 |
| 사람 검토 | 사람이 내린 최종 판단 | 아니오 |

상품 페이지의 "확인함 / 확인 전"은 이 네 칸을 그대로 보여 줍니다. "확인 전"은 나쁘다는 뜻이 아니라 아직 안 봤다는 뜻입니다.

## 용어 한 줄 설명

* **면 수(삼각형 수)** — 3D 모델이 몇 개의 삼각형 면으로 이뤄졌는지. 많을수록 무겁고, 모바일 웹 게임은 보통 모델 하나에 수천 면 안쪽이 안전합니다.
* **그리기 횟수(드로우콜)** — 화면 한 장을 그릴 때 그래픽카드에 몇 번 명령을 보내는지. 적을수록 빠릅니다. 재질을 합치면 줄어듭니다.
* **게임 기준(프로파일)** — 어떤 게임에 넣을지에 따라 다른 상한선. 모바일 웹, PC, 콘솔이 다릅니다.
* **스프라이트 시트** — 3D 모델을 여러 방향에서 찍어 한 장의 그림으로 붙인 것. 2D 게임에서 씁니다.
* **검사 증명서(Passport)** — 원본과 결과 파일의 지문(해시)과 전후 검사 점수를 한 파일에 적은 기록.
